Neon Cover Maker — turn your photos into GTA VI-style cover art: a three-panel poster maker with a Vice City neon-sunset grade, caption lettering, and one-step PNG export (1080×1080, 1080×1350, 1920×1080). Fully offline, zero dependencies.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080, load a photo, and export your cover.
